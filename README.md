# Solemn Home Portfolio Concept

A cinematic, responsive React website concept built as a portfolio case study.

## About

This project showcases:

- scroll-driven hero storytelling
- premium visual design and motion
- responsive layout and interaction patterns
- conversion-focused section structure

All names, contact details, and memorial content in this repository are sample/demo content for presentation purposes.

## Stack

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Vite

## Local Development

```sh
npm install
npm run dev
```

## Quality Checks

```sh
npm run build
npx tsc --noEmit -p .
npm run test
```

## Deploy (Vercel)

Direct deploy from local machine:

```sh
npm i -g vercel
vercel login
vercel
vercel --prod
```

The project is also compatible with GitHub import on Vercel using default settings (`framework: tanstack-start`).
